# Codeforces Solutions & Snippets

A collection of competitive programming templates and solutions organized by topic.

## Structure
- **snippets/**: Reusable code snippets by category
- **contest_solutions/**: Solutions organized by contest date
- **templates/**: Template files for quick start

## Usage
Copy snippets into your template and modify as needed for each problem.
